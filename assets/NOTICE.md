# Imagens das cartas

As 59 imagens PNG de `cards/` foram obtidas de [RoyaleAPI/cr-api-assets](https://github.com/RoyaleAPI/cr-api-assets), diretório `cards-150`. Elas são servidas pelo próprio site, sem usar o repositório como CDN. A revisão de origem e as URLs individuais estão em `sources.json`.

As ilustrações de Clash Royale pertencem à Supercell. Este projeto não é afiliado, endossado, patrocinado ou aprovado especificamente pela Supercell, e a Supercell não é responsável por ele. Veja a [Fan Content Policy](https://supercell.com/en/fan-content-policy/).

Carrasco e Executor são nomes usados na base anterior para a mesma carta; ambos apontam para `executioner.png`. O catálogo de treino mantém apenas Executor.
